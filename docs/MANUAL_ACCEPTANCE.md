# 最终手工验收清单

自动测试证明流程、安全边界和打包可运行；以下项目必须由美术人员在正式提交前目视确认。

## 客户端界面

- [ ] `1440×900`、`1152×720` 和最小窗口下无重叠、截断或无法点击区域。
- [ ] 简单模式无需理解 task ID、GLB/FBX 或 API 路由即可完成主流程。
- [ ] 节点图/预览分隔条可拖动；模型、骨架、动画、图片和对比预览正常。
- [ ] 付费节点显示参数与费用提示，取消后未创建任务。
- [ ] 日志默认折叠，失败时可看到可操作摘要。

## 当前角色质量

- [ ] 确认 `CharacterMesh_02` 是可忽略的刚性附件/眼睛，或在 Blender 中补权重。
- [ ] 检查肩、胯、膝、手腕、脚踝的 Bind Pose、抬臂、下蹲和 Idle 变形。
- [ ] 检查 27 条首尾值不同曲线对应的循环跳变、脚滑与 Root/Pelvis 偏移。
- [ ] 检查脚底接触、衣物穿插、轮廓、关键服装图案、材质分区和粗糙度层次。
- [ ] UE Preview Map 中材质、Skeleton、Animation Sequence 与默认播放正常。

## 泛化与复用性

- [ ] 使用第二个明显不同风格的人形角色，不改源码、不手改脚本、不重新接节点。
- [ ] 只替换参考图、项目名和公开艺术参数，复用同一 Comfy workflow 与 Studio 节点图。
- [ ] 输出相同目录结构的 Manifest、三视图、模型、绑定、动画、质量报告和 UE 报告。
- [ ] 中途停止并恢复一次，确认不重复创建已有付费任务。
- [ ] 导出 `.tacs-project.zip`，在另一目录导入并预览中间产物。
- [ ] 导出 `.tacs-profile.json`，确认其中没有 Key、绝对工具路径或 Comfy 地址。

## 送检包

- [ ] 在未安装系统 Node.js 的 Windows x64 机器上安装并启动 MSI 或 NSIS。
- [ ] 执行“一键环境自检”，缺少 Blender/UE/Comfy 时提示可操作。
- [ ] 通过设置页安装 TA Comfy 节点，重启 ComfyUI 后检测为 PASS。
- [ ] 重新计算并核对 `checksums.sha256`。
- [ ] 录制参考图 → 三视图/切分 → Meshy → Normalize → UE Preview Map 的演示视频。
- [ ] 在说明中保留“未商业代码签名，可能触发 SmartScreen”。
